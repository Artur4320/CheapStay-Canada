# EasyWay

**Your trip. Every option. One place.**

EasyWay is a Canada-first travel planner concept. It is designed to compare different ways to travel, show individual journey legs, transfers, waiting times and total trip costs.

## Current prototype
- Route origin and destination
- Departure date picker
- Solo and group traveller counts
- Selectable transport modes: bus, ferry, train, flight, car and local transit
- No budget limit by default; intended to show all available prices
- Overnight accommodation is opt-in only
- Android app built with Kotlin and Jetpack Compose

## Development status
This is an early UI prototype. Live schedules, fares, availability, booking links and map-based route results are not connected yet. The app does not currently return live travel options or confirmed prices.

## Build
Run gradle assembleDebug with Android SDK and Java 17 installed.
